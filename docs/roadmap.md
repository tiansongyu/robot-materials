# 学习路线：从材料名称到工程判断

机器人材料学处在材料科学、机械设计和制造工艺的交界处。目标不是背完材料牌号，而是能解释：一个零件为什么用这种材料，可能在哪里失效，又该用什么证据证明它适合。

## 六个学习阶段

以下时长是学习安排建议，可按基础调整。每阶段都留下一个成果，比只看完章节更有用。

| 阶段 | 建议投入 | 核心问题 | 动手成果 |
|---|---|---|---|
| 1. 力与变形 | 4–6 小时 | 力从哪里来？变形允许多大？ | 画一根机械臂的受力图 |
| 2. 组织与性能 | 4–6 小时 | 同种金属为什么有不同状态？ | 解读一份带状态的材料数据表 |
| 3. 金属与塑料 | 6–10 小时 | 铝、钢、镁与聚合物如何分工？ | 为五个机器人零件列候选材料 |
| 4. 制造与连接 | 6–10 小时 | 工艺会怎样改变零件性能？ | 画出打印方向、紧固件和加工基准 |
| 5. 计算与筛选 | 4–6 小时 | 重量、刚度和成本怎样一起比较？ | 复算悬臂梁，写选材记录 |
| 6. 验证与改进 | 8–12 小时 | 计算在哪些地方不可靠？ | 测一次挠度、蠕变与连接松弛 |

## 你真正需要掌握的知识点

**结构承载**包括拉伸、弯曲、扭转、屈曲和接触应力。机械臂不仅要不折断，还要控制末端位移；轴不仅传递扭矩，还可能承受皮带张力引起的弯矩。

**运动与控制**要求理解运动惯量、振动模态和阻尼。末端减轻一点质量，可能同时降低多个关节的负担；但把支架做薄导致固有频率下降，也可能使控制更难调。

**寿命与环境**包括疲劳、蠕变、磨损、腐蚀、吸湿和热老化。短时承重成功不能证明长期工作的可靠性。

**制造与装配**包括尺寸公差、表面粗糙度、热处理变形、连接预紧、层间结合和批次追溯。采购的是“材料加制造状态”，实际工作的则是“零件加连接”。

## 按机器人类型调整重点

| 项目 | 优先学习 | 容易遗漏 |
|---|---|---|
| 桌面机械臂 | 弯曲刚度、关节配合、循环疲劳 | 电机附近的塑料蠕变和温升 |
| 轮式机器人 | 机架、冲击、紧固件、轮胎摩擦 | 路面振动、涉水和电偶腐蚀 |
| 足式机器人 | 疲劳、冲击、质量分布、连接 | 缺口、跌落、轴承座松动 |
| 灵巧手与夹爪 | 弹性体、摩擦、磨损、柔顺性 | 垫片压缩永久变形、油污 |
| 户外机器人 | 耐候、密封、腐蚀、热管理 | 紫外线、结露和异种材料接触 |

## 结业任务

选一个小型室内机器人，至少分析机架、运动连杆、电机座、传动轴、外壳和夹爪垫六类零件。每类写明功能、限制、两个候选材料、制造方式、最可能的失效以及验证方法。尚未取得的数据写成待测项，不能用材料名称替代证据。

基础力学可继续参考 [MIT 3.11 课程目标](https://web.mit.edu/3.11/www/abet.html)，它覆盖拉压、扭转、弯曲及组合载荷。
