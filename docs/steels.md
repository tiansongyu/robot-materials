# 钢、铁与铸铁：承载、传动和稳定基座

日常所说的“铁件”可能是低碳钢、铸铁，甚至只是在说一种磁性金属。机器人采购和设计必须使用实际牌号与状态。

## 三类材料不要混用

纯铁是成分概念；钢是以铁为基体、控制碳及其他元素的合金；铸铁通常具有更高碳含量，组织和铸造特性明显不同。钢与铸铁的常用分类边界在约 2% 碳附近，但不能只用一个阈值判断所有特种成分。实际按产品标准和组织类别辨认。

| 材料类别 | 主要特点与设计关注 | 机器人中的候选零件 |
|---|---|---|
| 低碳结构钢 | 易获得，连接工艺成熟；需防腐 | 焊接机架、底座、安装板 |
| 中碳钢，如 45 钢 | 性能依赖热处理与截面 | 轴、销、机加工传动件 |
| 合金结构钢，如 40Cr | 可通过热处理取得适合的强韧组合 | 受载轴、齿轮、连接件 |
| 奥氏体不锈钢，如 304/316 | 耐蚀性需按环境选；加工与咬合需注意 | 湿环境支架、外露紧固件 |
| 灰铸铁 | 石墨片形态影响性能与阻尼 | 固定机座、设备基体 |
| 球墨铸铁 | 球状石墨有利于获得较好的延性 | 某些承载铸件与壳体 |

牌号仅为认识类别的示例；GB、EN、ASTM、JIS 中相似名称不意味着可无条件互换。特别是热处理、尺寸范围和验收项目要逐项对应。

## 为什么钢仍然适合机器人？

钢密度高，但弹性模量也高。细轴、齿轮和轴承接口往往受尺寸、接触应力、耐磨与疲劳约束，而不只是总重量。把钢件换成铝件之后，如果需要大幅增加截面、增加钢套和更复杂的连接，整机收益未必明显。

高强钢主要提高抵抗屈服的能力；若保持几何不变，弹性挠度不会按强度提升比例降低。[SSAB 的结构刚度说明](https://www.ssab.com/en/support/how-to-design/general-design/structural-stiffness/20-questions)解释了材料模量和结构形状的区别。

## 热处理：表面和芯部承担不同任务

轴和齿轮常希望表面抵抗接触损伤，芯部保留承载与韧性。调质、表面淬火、渗碳和氮化是不同路线，不适用于所有牌号，也不能互相替换。

设计时应同时给出所需硬度、有效硬化层、关键位置、允许变形及后续精加工要求。只有“淬硬”两个字不足以让供应商交付可验证的零件。尖角、键槽、台阶与热处理残余应力还会影响疲劳。

## 不锈钢并非“永不生锈”

不锈钢依赖表面钝化状态。304 和 316 的耐蚀性不能只按名称判断；氯离子、温度、缝隙、表面污染和清洁条件都重要。316 含钼，通常比 304 更适合某些点蚀环境，但不能据此宣称普通 316 适用于所有海水工况。来源：[Outokumpu 耐大气腐蚀说明](https://www.outokumpu.com/en/expertise/2025/stainless-steel-and-atmospheric-corrosion-what-you-need-to-know)。

不锈钢也不是一种确定的磁性类别。奥氏体、铁素体、马氏体组织不同，加工状态还可能改变磁响应；磁铁测试不能作为完整材质鉴定。

## 铸铁为什么更适合固定基座？

固定底座不必像运动连杆那样极端减重，可以利用铸造成形、结构质量和阻尼特征。灰铸铁中的片状石墨也使拉伸、冲击与缺口响应不同于钢，不能把钢结构公式中的许用应力直接移植过来。

对于个人小批量项目，自制铸铁底座可能不经济。学习时先考虑现成机座、钢板或焊接结构，把铸造放到具备供应链和批量条件后再评估。

## 练习：写清一根轴的订单

至少包括材料标准与牌号、交货状态、热处理要求、轴承配合段公差、表面粗糙度、圆角、形位要求和检验方式。不要从网络上抄一个“40Cr 强度”就完成验算。钢组织与制造的进一步阅读见 [Outokumpu 材料手册入口](https://www.outokumpu.com/en/expertise/2021/handbook-of-stainless-steel)，其中不锈钢部分不应扩展为全部钢种的数据来源。
