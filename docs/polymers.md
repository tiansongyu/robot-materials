# 塑料：PLA、PETG、TPU 与工程塑料

塑料能减轻重量、形成复杂外形、绝缘或提供柔顺接触。它的性能通常比金属更依赖时间、温度、湿度和加工方式。先区分使用功能，再选择具体牌号。

## “TPG”需要核对原始标签

仅凭“TPG”无法确定是哪种塑料。你可能想到的是 PETG 或 TPU，但本站不将它们视为同义词。Momentive 使用 TPG 表示 **Thermal Pyrolytic Graphite，热解石墨**，属于热管理材料，不是常见打印塑料。今后采购时应核对包装英文全称和数据表。[来源：Momentive TPG](https://www.momentivetech.com/materials/ceramic-materials/thermal-pyrolytic-graphite-tpg)。

## 机器人原型常用材料

下表是候选用途与风险提示，不是对所有配方的定量排名。

| 材料 | 为什么考虑它 | 优先尝试的零件 | 重点限制 |
|---|---|---|---|
| PLA，聚乳酸 | 易成形，便于验证几何 | 外观样件、尺寸与装配验证件 | 温升、持续受载和冲击需验证 |
| PETG，改性聚酯 | 常用于功能打印原型 | 罩壳、支架原型、线缆导向件 | 蠕变、拉丝、尺寸和层间性能 |
| TPU，热塑性聚氨酯 | 柔顺、可大变形 | 夹爪垫、缓冲、防滑件 | 硬度不等于刚度；有滞后和压缩变形 |
| ABS | 常见工程热塑性路线 | 有设备条件的外壳原型 | 翘曲、排放、耐候性 |
| ASA | 可作为户外外壳候选 | 室外罩壳、非精密外观件 | 工艺、受载温度与实际耐候验证 |
| PA，尼龙 | 耐磨与韧性用途广 | 齿轮、滑动件、卡扣候选 | 吸湿、尺寸改变，PA6/PA12 不能混称 |
| PC，聚碳酸酯 | 冲击与热性能方向的候选 | 防护罩、较热区域样件 | 加工条件、应力开裂、配方差异 |
| POM，聚甲醛 | 适合机械加工与滑动应用 | 齿轮、衬套、低摩擦导向件 | 粘接难、热与介质适用性需查表 |
| PEEK / PEI | 较高温度或特殊工况候选 | 有明确需求的功能部件 | 成本、加工设备、牌号与认证 |

打印材料与设备要求可初查 [Prusa 材料指南](https://help.prusa3d.com/filament-material-guide)。POM 的机械加工、吸湿与滑动特点参考 [Ensinger POM](https://www.ensingerplastics.com/en/thermoplastic-materials/pom)。

## PLA：先用来暴露设计问题

PLA 很适合验证孔位、装配路径和运动干涉。它不应该因为容易打印，就被默认用于温热电机的长期承载支架。即便短时拉伸性能看起来不错，实际结构仍可能因温升与时间效应失去精度。

“PLA+”等商品名没有统一的力学定义；退火或填充改性也会改变尺寸与性能。需要购买具体产品的数据，而不是继承普通 PLA 的所有结论。[Prusa PLA 使用说明](https://help.prusa3d.com/article/pla_2062)、[Prusament PLA 数据表](https://prusament.com/wp-content/uploads/2022/10/PLA_Prusament_TDS_2021_10_EN.pdf)。

## PETG：功能原型也要检查长期变形

PETG 与 PLA 的取舍应包含韧性、打印性、刚度和环境条件，不能简化为 PETG 在所有方面更强。用在支架时，应测工作温度下的持续载荷挠度；用在卡扣时，还要检查循环寿命与过盈量。[Prusa PETG 说明](https://help.prusa3d.com/article/petg_2059)。

## TPU：为接触与柔顺性选材

Shore A 与 Shore D 是不同硬度标尺，不可直接比较数字大小。即便同为某个 Shore A 硬度，不同 TPU 配方、壁厚、填充和打印方向也可能产生不同的压缩刚度。

夹爪垫要一起考虑摩擦系数、接触面积、允许压强、磨损、油污、清洁剂与压缩永久变形。摩擦系数属于材料配对和接触条件，不是 TPU 的一个固定常数。柔顺垫不宜同时承担精确定位基准的职责。

## PA 与 POM：两个不同的工程选择

PA 吸湿后尺寸和力学性质可能改变。应区分“干态测试”“调湿后测试”和实际环境平衡状态。打印前干燥保证加工质量，不等于成品以后不会吸湿。[Ensinger 工程塑料手册](https://www.ensingerplastics.com/en-us/-/media/ensinger/files/document-teaser-files/brochures/shapes/engineering-plastics-manual-english.ashx)。

POM 可用棒板材切削，适合考虑尺寸稳定与滑动性能的小零件。但“低摩擦”不是可以忽略润滑、磨损和发热的理由；齿轮还要检查齿根应力与齿面接触。不能把注塑 POM 数据直接当作打印 PA 的替代值。

## 不要用这些方法做排名

1. 将不同试验方法的冲击值放在同一栏比较。
2. 用喷嘴温度作为成品耐温。
3. 用干态 PA 数据设计湿环境精密配合。
4. 用原料粒子的拉伸强度验算所有方向的打印件。
5. 用“100% 填充”代替层间强度和连接测试。

**学习任务：** 给外壳、夹爪垫、齿轮和电机座分别写出最重要的两个指标。你会发现它们不应该共用同一份材料排名。
