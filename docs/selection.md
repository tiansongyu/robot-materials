# 选材方法：先排除，再比较，再验证

从材料名称开始容易陷入“哪种最好”的争论。更有效的起点是零件的功能和可测量要求。

## 第一步：写出六类约束

| 约束 | 应写成什么 | 模糊写法的问题 |
|---|---|---|
| 载荷 | 力、扭矩、冲击、循环谱与方向 | “能承重”忽略动态工况 |
| 精度 | 允许位移、角度、间隙 | “很硬”无法验证 |
| 环境 | 温度、湿度、UV、介质、时间 | “耐高温”没有温度与时长 |
| 几何 | 外形空间、壁厚、接口 | 任意加厚可能装不下 |
| 制造 | 数量、设备、公差、后处理 | 原料便宜不等于零件便宜 |
| 寿命 | 次数、工作时长、维护与失效后果 | 短时成功不代表寿命足够 |

## 第二步：把硬约束与偏好分开

承载、温度、尺寸和工艺不可行的候选先排除。剩下的再比较质量、成本、交期、维修和外观。不要让低价格的高分“抵消”耐温不达标。

评分表应保留权重、评分依据和敏感性检查。权重来自项目目标，并非材料本身的科学常数。对权重稍作调整就反转的排名，应优先补数据或做样件。

## 第三步：按零件功能初筛

以下是待验证的候选方向，不是成品设计。

| 零件 | 可比较的候选 | 优先约束 | 常见遗漏 |
|---|---|---|---|
| 固定机架 | 钢结构、铝型材 | 刚度、装配、成本 | 连接滑移与地脚条件 |
| 运动连杆 | 铝合金、碳纤维结构、镁合金 | 质量、刚度、疲劳 | 端接总质量与局部损伤 |
| 轴与销 | 合适状态的钢或不锈钢 | 接触、疲劳、配合 | 台阶圆角、热处理变形 |
| 齿轮 | 钢、POM、PA | 扭矩、速度、噪声、磨损 | 温升、润滑、湿度 |
| 电机座 | 铝合金、钢、经验证的工程塑料 | 温升、刚度、预紧保持 | 长期蠕变 |
| 外壳 | PLA 原型、PETG、ASA、板材 | 冲击、耐候、装配 | 壳体是否意外承担结构载荷 |
| 夹爪垫 | TPU、硅橡胶等 | 摩擦、柔顺、耐久 | 油污与压缩永久变形 |

## 第四步：算一轮，但不止算强度

至少同时计算质量、关键变形与名义应力。运动结构还要看惯量与振动，长期载荷看蠕变，重复载荷看疲劳，配合部位看接触、磨损与尺寸变化。

安全系数必须对应失效模式与数据可信度。线性静强度中的一个系数，不能证明疲劳、冲击、屈曲、层间破坏和长期蠕变都安全。也不能通过无限加大系数弥补未知载荷。

## 第五步：留下一页选材记录

可直接复制下面的模板：

```text
零件名称 / 图纸版本：
功能与载荷路径：
载荷工况 / 环境 / 寿命目标：
允许变形 / 尺寸与质量限制：
候选材料（完整牌号、状态、工艺）：
数据来源（版本、试验方向、温湿度）：
硬约束筛选结果：
计算模型 / 假设 / 尚未覆盖的失效：
制造、连接、表面与检验方案：
样件编号 / 测试记录 / 未解决项：
选择理由 / 复查触发条件：
```

换耗材、供应商、打印方向、热处理、涂层或关键尺寸，都可能触发复查。更改名称相同的材料，不代表工程条件没有变化。
