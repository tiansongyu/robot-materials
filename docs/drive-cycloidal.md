# 摆线针轮：从偏心摆动中取出慢速转动

本页先用**针齿圈固定、偏心轴输入、输出销法兰输出**的单盘模型解释原理，再说明双盘与 RV。组成和运动关系参考 [Sumitomo：CYCLO 技术手册](https://assets.sumitomodrive.com/sites/default/files/nqikej116/files/2022-08/D6000_CAT_DE_991470_07_2022_web.pdf)。

## 端面图：盘心绕圈，盘体反向慢转

```{figure} _static/drives/cycloidal-section.svg
:target: _static/drives/cycloidal-section.svg
:alt: 固定外圈上排列针齿，偏心轴推动摆线盘，盘上六个大孔中放入输出销。摆线盘中心与主轴中心相距偏心距 e。

外圈灰色针齿与内侧绿色输出销承担不同职责。盘心与主轴心的距离为偏心距 e；轮廓仅示意波瓣，不是精确摆线齿形。
```

输入轴的偏心部位通过轴承推动摆线盘，使盘心绕主轴心转动。盘的外缘受到固定针齿圈约束，在公转的同时缓慢反向自转。这两种运动叠加，看上去像盘在壳体里“摇摆”。

外圈针齿属于固定壳体一侧；内侧输出销属于输出法兰一侧。混淆这两组销，会误以为输出也必须随盘心偏摆。

## 概念爆炸图：大孔为什么不能做成销的直径

```{figure} _static/drives/cycloidal-exploded.svg
:target: _static/drives/cycloidal-exploded.svg
:alt: 偏心轴与轴承、固定针齿圈、带输出大孔的摆线盘、带销输出法兰依次分离。组装时输出销伸入大孔，摆线盘嵌入针齿圈。

单盘模型用于看清传动关系。图中将输出销画成伸向摆线盘的短柱，实际产品可采用滚套等结构。
```

输出销进入盘上的较大圆孔。孔允许盘的偏心位移，孔壁又能对销施力，因而把盘的慢速自转传给绕主轴中心旋转的法兰。法兰由自身支承约束，不随盘心公转。

在理想圆孔、圆销模型中，孔与销的**半径差**应容纳偏心距 $e$；相应直径差约为 $2e$。若有滚套，要用滚套外径计算。实际公差、预紧、变形与润滑间隙另行设计，不能直接拿这条几何关系生成加工尺寸。该说明是几何推导，图中间隙作了夸张。

## 减速比与一齿差

设固定针齿数为 $N$、摆线盘波瓣数为 $n$。对本页的简单机构，理想带符号传动比为：

$$
i=-\frac{n}{N-n}
$$

常见一齿差 $N=n+1$ 时，$i=-n$。**教学假设：** 12 根针齿配 11 个波瓣，则输入转一圈，输出反向转 $1/11$ 圈，约 $-32.73°$；输入 $1100\ \mathrm{r/min}$ 时输出 $-100\ \mathrm{r/min}$。图中的波瓣曲线为示意，不能用来验证实际啮合干涉。

## 双盘和 RV 增加了什么

为了平衡偏心作用、改善载荷分配，产品可采用两片摆线盘及相位相配的偏心结构。具体齿形、偏心相位和装配标记须按产品图纸确定，不能只把两个相同模型叠起来。

常见 Nabtesco RV 采用两级结构：前级正齿轮把输入传给曲柄轴，曲柄轴偏心段驱动两片 RV 齿轮，再通过曲柄轴等构件把运动传到输出。它的输出连接方式与上面单盘输出销模型不同。参见 [Nabtesco：RV 工作原理与分解图](https://precision.nabtesco.com/en/products/introduction/)。

```{mermaid}

:alt: 输入齿轮经正齿轮驱动曲柄轴，偏心段带动双摆线盘，固定针齿壳体约束其运动，曲柄轴与输出构件传出运动。
flowchart TD
    A[电机输入齿轮] --> B[前级正齿轮]
    B --> C[曲柄轴与偏心轴承]
    C --> D[双摆线盘 / RV 齿轮]
    E[固定针齿壳体] --- D
    D --> F[经曲柄轴与输出构件传递]
```

因此，本页的 $i=-n$ 不能直接当成整台 RV 的总传动比。总比值还依赖前级齿数、连接关系与输出方式。

## 结构带来的特点

摆线盘与多处针齿接触，为载荷分担提供条件；偏心运动也带来轴承受力、动平衡与振动问题。间隙、预紧、轮廓精度和支承刚度会影响回差与效率。具体产品的承载与冲击能力参见 [Sumitomo：摆线传动说明](https://us.sumitomodrive.com/en-us/cycloidal-gearboxes-cycloidal-drives)，不要把某个系列的指标推广到所有自制摆线机构。

**自查：** 如果输出销被紧紧固定在摆线盘上，完全不允许相对偏心位移，会怎样？定轴输出法兰与偏心盘的运动要求冲突，机构可能卡住或迫使其他部件变形。
