# 谐波：让啮合区域沿柔轮移动

本页采用常见的**双波、杯形柔轮**：波发生器输入，刚轮固定，柔轮输出。其三个核心件是波发生器、柔轮和刚轮。参考 [Harmonic Drive：工作原理](https://legacy.harmonicdrive.net/reference/operatingprinciples/)；该厂商页面含装配及运动演示入口。

## 端面图：变形在转，柔轮缓慢转

:alt: 刚轮内包椭圆形柔轮，波发生器位于柔轮内，两处主要啮合区位于椭圆长轴两端。

图中夸大椭圆变形并省略单个轮齿；红点只标示啮合区，不是滚珠或固定销。
```

波发生器通常由椭圆凸轮与能随之变形的薄壁轴承组成。它撑开柔轮杯口，使长轴两端附近的外齿与刚轮内齿啮合。转动输入后，长轴方向随之转动，啮合区域沿周向移动；柔轮材料本身以较慢速度转动。

柔轮的弹性变形是设计需要的正常工作方式。若把柔轮替换成同形状的厚壁刚性杯，这个原理就无法按原样工作。

柔轮不是一张薄圆片。杯口附近有外齿，杯壁传递转矩，杯底与输出连接；齿部在此图中简化成杯口环。
```

波发生器轴承与输出支承轴承职责不同。前者使变形与相对运动得以发生；后者如何承担负载的力与力矩，取决于完整减速器或关节模组的结构。

## 用一圈输入理解齿数差

设柔轮齿数为 $Z_f$，刚轮齿数为 $Z_c$，固定刚轮、波发生器输入时：

$$
i=\frac{\omega_\mathrm{wave}}{\omega_f}=-\frac{Z_f}{Z_c-Z_f}
$$

**教学假设：** $Z_f=200$、$Z_c=202$，则 $i=-100$。输入每转一整圈，柔轮相对固定刚轮反向移动两个柔轮齿距，也就是 $2/200$ 圈。

| 波发生器累计转角 | 柔轮累计转角 | 观察重点 |
|---|---|---|
| 0° | 0° | 标记柔轮上的一个材料点 |
| +90° | −0.9° | 椭圆长轴转了 90°，材料点只慢移 |
| +180° | −1.8° | 椭圆外观重复，材料点已退一个齿距 |
| +360° | −3.6° | 完成一圈输入，材料点退两个齿距 |

上表是理想运动学关系，负号表示反向；它不是接触力或变形量的仿真。输入 $1200\ \mathrm{r/min}$ 时，输出为 $-12\ \mathrm{r/min}$。双波齿数差和运动过程可对照 [Harmonic Drive 官方原理演示](https://www.youtube.com/watch?v=nj1vO3cP7ug)。

## 结构带来的特点

小齿数差使单级能够实现较大的减速比，多个齿在啮合区共同承载。厂商的低回差或零回差表述有具体产品与测试条件；即使回差很小，负载下仍存在弹性扭转，不能据此认为输出位置完全不变。柔轮重复变形也意味着疲劳、材料与热处理、装配和润滑必须一起考虑。参见 [Harmonic Drive：应变波齿轮基础](https://www.harmonicdrive.net/media/3355/final-vol-1_basics-of-strain-wave-gears_md6698_harmonicdrive_v2.pdf)。

本图只代表杯形双波结构；礼帽形、平面型及其他波数结构不能直接用这张爆炸图解释。

**自查：** 输入转半圈后，椭圆方向看起来和起点一样，输出是否回到起点？没有。形状重复不等于柔轮材料点回到原位。
