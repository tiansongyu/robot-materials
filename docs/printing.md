# 增材制造：打印参数也是零件规格

打印件不是把均质材料放进任意形状。挤出道路、层间界面、孔隙与热历史会形成方向差异。设计一个打印件，需要同时设计载荷路径和制造方向。

## FFF / FDM：先看力怎样跨过层间

对承受拉力或弯曲的零件，避免让关键受拉区域完全依赖未经验证的层间结合。例如 L 形支架在根部可能发生剥离式破坏；只增加填充率未必能修复这一点。

## 外壁、填充与几何

弯曲时外侧材料贡献较大，因此外壁厚度、截面高度和加强筋值得先评估。填充可以支撑面板并改变整体刚度，但不能把不同图案和密度的填充件都用实体梁模型精确表示。

内部尖角改圆角、避免突然变薄、让螺栓附近具有连续承载路径，通常比盲目追求最高填充更有意义。这里不提供通用壁数或层高，因为喷嘴、材料和零件尺寸会改变合适的设置。

## 工艺数据应记录到什么程度？

| 类别 | 最低记录内容 |
|---|---|
| 材料 | 品牌、牌号、颜色、批次、开封时间、干燥历史 |
| 设备 | 打印机、喷嘴材质与直径、封闭与腔温条件 |
| 参数 | 层高、外壁、填充、温度、冷却、速度、方向 |
| 后处理 | 支撑去除、退火、镶嵌、机加工、调湿 |
| 检验 | 质量、孔径、翘曲、缺陷、受载测试 |

打印前干燥按供应商规定操作；过高温度也可能损坏材料或线盘。Prusa 的[材料与设备指南](https://help.prusa3d.com/filament-material-guide)适合做设备需求初筛，不是所有品牌的通用工艺卡。

## 螺纹与轴承座

频繁拆装的小螺纹可以比较热熔嵌件、捕获螺母或贯穿螺栓。嵌件周围必须有足够承载材料，安装热量和几何要受控；嵌件并不会自动消除拔出或蠕变。

需要保持夹紧力时，可考虑金属压缩套筒，使螺栓夹紧载荷通过稳定路径传递。打印轴承孔要验证尺寸、圆度、温升及长期松动；高精度位置可考虑加工金属座。配合方式取决于载荷、温度和拆装要求，不统一规定过盈量。

## SLA、SLS 与 MJF 的边界

光固化树脂可获得细节，但树脂类别、清洗和后固化会影响性能。SLS/MJF 聚合物也受工艺、方向、孔隙与后处理影响。不能以表面更光滑或单件价格更高，就推断它更适合承载。

增材金属也需要考虑孔隙、残余应力、热处理与精加工。机器人入门可以先掌握 FFF 与常规机加工，不必一开始引入所有设备路线。

## 一项能学到东西的比较

用相同耗材、相同截面和一致参数，制作两种受力方向的样件，在小载荷下比较位移，再观察卸载后是否恢复。保留至少三个重复样件，记录离散性。结论只适用于记录的工艺，不推广为“PLA 永远比 PETG 强”。具体记录方法见[验证实验](testing.md)。
