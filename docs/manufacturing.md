# 加工、连接、表面与环境

材料选择应与制造路线同步进行。一个理论上合适的材料，如果无法稳定加工、装配和检验，就不是可用的工程方案。

## 制造方式改变哪些问题？

| 路线 | 有利条件 | 需要提前设计 |
|---|---|---|
| 板材切割与折弯 | 罩壳、小批量结构 | 折弯半径、孔到弯边距离、回弹 |
| CNC 切削 | 精密接口与小批量零件 | 基准、装夹、刀具可达、薄壁变形 |
| 挤压型材 | 长等截面框架 | 截面方向、端部连接、直线度 |
| 铸造或压铸 | 批量复杂壳体 | 拔模、壁厚、孔隙、模具成本 |
| 注塑 | 批量聚合物零件 | 收缩、熔接线、纤维取向、模具 |
| 焊接 | 机架与结构组合 | 热影响区、残余应力、变形、疲劳 |
| 增材制造 | 快速复杂原型 | 方向、界面、后处理和重复性 |

公差不要全图统一收紧。轴承位、齿轮中心距和定位面可能需要严格控制，非功能外形则可以放宽。关键是让公差对应功能，并留出测量手段。

## 连接：预紧力比“拧得很紧”更有意义

螺栓连接依靠预紧形成夹紧作用；工作外载由螺栓与被连接件的刚度共同分配。预紧不足可能导致分离或滑移，过大则可能压坏塑料、拉坏螺纹或使螺栓超载。

扭矩只是控制预紧的一种间接方法，受摩擦、润滑和表面状态影响。不能把某个干态螺栓的扭矩表直接用于润滑或不同涂层的连接。薄软材料还要检查垫圈下的压应力、孔壁承压和长期松弛。

防松设计应针对实际滑移、振动和维护条件选择，不能把任何一种垫圈或胶剂当作通用保证。概念与计算可参考 [NASA Fastener Design Manual，1990](https://ntrs.nasa.gov/api/citations/19900009424/downloads/19900009424.pdf)；它是经典参考手册，不是所有机器人项目的现行验收标准。

## 胶接、焊接与机械紧固怎样选？

胶接可以分散载荷，但对表面状态、胶层厚度、固化和剥离敏感。焊接可以减少紧固件，但会改变局部组织与变形。机械紧固便于拆装，却引入孔、接触应力和额外质量。选择时先看维护、材料兼容与载荷方向，不是按“高级程度”排序。

对精度敏感的结构，可采用粗加工、必要的稳定化处理、精加工和检验的工序安排。具体安排由材料、几何和供应商能力决定；不能承诺一个工序顺序适合所有零件。

## 腐蚀：材料组合也是设计变量

异种导电材料接触，并同时存在电解质时，可能形成电偶腐蚀。材料组合、阴阳极面积比例、涂层缺陷与排水条件影响严重程度。

铝与钢、镁与其他金属、碳纤维与铝的组合都值得检查。可采用合适的绝缘隔离、密封和排水，避免把水困在连接缝隙中。涂层破损后的行为也要评估。关于环境条件和试验外推边界，参见 [Outokumpu 腐蚀数据使用说明](https://www.outokumpu.com/en/products/corrosion-tables)。

## 表面处理不是只改颜色

阳极氧化、镀层、喷涂、钝化等处理可能影响摩擦、配合尺寸、导电接地和疲劳。轴承位、螺纹、胶接区与电接触区是否遮蔽，要在图纸或工艺要求中说明。不能直接把处理前尺寸视作最终尺寸。

## 热与电的跨学科问题

热膨胀近似 $\Delta L=\alpha L\Delta T$。不同材料装配后热膨胀不一致，可能改变轴承间隙、定位精度或夹紧状态。散热路径还包含界面接触热阻，不能只比较材料导热率。

金属壳体有利于某些散热与屏蔽设计，同时也要求可靠绝缘与接地。带碳填料的塑料不一定保持普通塑料的绝缘特性；阻燃、导电和耐温属于不同属性，均需具体牌号数据。
