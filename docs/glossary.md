# 术语与数据表速查

| 术语 | 英文 / 符号 | 如何使用 |
|---|---|---|
| 密度 | Density，ρ | 质量 = 密度 × 体积；1 g/cm³ = 1000 kg/m³ |
| 弹性模量 | Young’s modulus，E | 材料弹性关系，不等于整个零件的刚度 |
| 剪切模量 | Shear modulus，G | 与扭转和剪切有关 |
| 屈服强度 | Yield strength | 用于判断塑性变形起始，需明确测试条件 |
| 抗拉强度 | Ultimate tensile strength | 拉伸试验的最大工程应力 |
| 断后伸长率 | Elongation at break | 与试样和标距有关，不是任意结构的允许应变 |
| 截面二次矩 | Second moment of area，I | 单位为长度四次方，与弯曲刚度有关 |
| 质量转动惯量 | Mass moment of inertia | 单位 kg·m²，与角加速度有关 |
| 缺口效应 | Notch effect | 孔、槽、台阶改变局部应力及疲劳行为 |
| 疲劳 | Fatigue | 重复载荷损伤，需载荷谱或明确循环条件 |
| 蠕变 | Creep | 载荷持续时变形随时间增长 |
| 应力松弛 | Stress relaxation | 变形维持时应力随时间下降 |
| 玻璃化转变 | Glass transition，Tg | 非晶部分链段运动的转变 |
| 热变形温度 | HDT | 指定方法与载荷的试验指标 |
| 各向异性 | Anisotropy | 性能随方向变化 |
| 电偶腐蚀 | Galvanic corrosion | 导电接触与电解质条件下的材料配对问题 |
| TDS | Technical data sheet | 性能与加工信息，区分典型值与保证值 |
| SDS | Safety data sheet | 危害与安全处理信息，不替代力学数据 |
| 调湿 | Conditioning | 控制试样测试前的温湿状态 |
| 牌号与状态 | Grade and temper / condition | 一起确定材料规格 |

## 常见问答

**7075 一定比 6061 更适合机械臂吗？** 不一定。先判断限制来自强度、刚度、连接还是耐蚀性，然后核对状态与制造路线。

**铁会被磁铁吸住，不锈钢不会吗？** 不能这样分类。不锈钢有多种组织，磁性还可能随加工状态改变。

**碳纤维一定比铝更轻、更强吗？** 需要比较具体铺层、载荷方向、几何与完整连接。纤维性能不能代替整件性能。

**打印填充设为 100% 就能使用注塑强度吗？** 不能。层间界面、孔隙、热历史与方向仍可能不同。

**能直接用一张材料排名表采购吗？** 只能用于初筛。订单还需牌号、状态、尺寸、加工、环境和检验要求。

**材料成本该怎样比较？** 比较合格零件的总成本，包括原料、加工、模具、表面处理、检验、报废、装配与维护；不要只比每公斤价格。
