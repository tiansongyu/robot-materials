# 验证实验：把材料结论变成证据

试验要回答明确问题。入门测试的价值在于发现模型遗漏、比较一致工艺下的趋势；它不能自动替代标准化材料试验或批量验收。

## 实验一：小载荷挠度

**问题：** 同一几何不同材料，或者同一材料不同方向，弹性变形有什么差异？

1. 记录样件长度、宽高、质量、材料状态和制造方向。
2. 使用稳定夹具，测量真实悬伸长度；固定位置保持一致。
3. 在防护与小载荷条件下分级施力，测末端位移，避免手进入载荷下方。
4. 每级卸载，记录是否恢复；出现裂纹、明显永久变形或夹具滑移就停止。
5. 至少重复三个样件，报告每个数值、平均值与范围，不只挑最好的一件。

拟合低载荷区的 $F/\delta$ 得到零件刚度，再与梁模型比较。尺寸测量尤其重要，因为矩形截面高度以三次方影响理论挠度。位移里还包含夹具柔度和滑移。

## 实验二：室温持续载荷与恢复

**问题：** 塑料短时看起来很稳，几小时后会怎样？

使用低风险载荷，在相同环境中记录 0、10、30、60 分钟以及后续预定时刻的位移。卸载后继续测恢复过程。时间点属于教学安排，不是标准试验条件。

同时保留无载荷对照件，记录温度与湿度。观察到的漂移可能同时包含蠕变、夹具滑动和环境变化，必须排查。短时间数据不可未经验证就外推多年寿命。

## 实验三：连接保持能力

**问题：** 相同材料，贯穿螺栓、捕获螺母与嵌件有哪些不同？

制作相同外形的低载荷样件，记录装配条件，比较重复拆装后的间隙、裂纹、压陷与松动。若需要拔出力或预紧保持的定量结论，应使用受控试验装置；不能凭手感排名。

## 实验四：吸湿与尺寸

选择允许相关处理的 PA 试样，记录干燥后质量与尺寸，再在记录的室内环境中定期测量。用未处理对照件排查仪器漂移。干燥条件必须来自供应商，不能用食品烤箱随意加热未知材料。

比较时注意称量分辨率、表面水、测量温度与时间。水分进入厚样件需要时间，短时质量不变并不证明不会吸湿。

## 失效分析顺序

先保存失效零件和现场记录，再确认载荷、环境及加工批次，接着判断失效起点和扩展位置。分清是材料本体破坏、连接滑移、尺寸干涉，还是模型假设错误。

| 现象 | 候选原因 | 下一步检查 |
|---|---|---|
| 卸载后仍弯曲 | 屈服、蠕变、装配滑移 | 时间记录、连接标记、局部应变 |
| 打印件沿层开裂 | 层间结合或受力方向问题 | 打印日志、干燥记录、方向对照 |
| 孔变大、轴松动 | 磨损、蠕变、配合或温升 | 温度、孔径随时间变化 |
| 突然断裂 | 缺陷、缺口、脆性或疲劳等 | 起裂区、断口、历史载荷 |
| 接头附近腐蚀 | 积水、电偶、涂层损伤 | 材料配对与排水路径 |

这些是诊断假设，不是仅靠外观就能确定的原因。关键件需要合适的无损检测、显微分析或专业实验室支持。

## 标准试验要查哪些条件？

金属拉伸常见 ISO 6892-1 / ASTM E8/E8M，塑料拉伸常见 ISO 527 / ASTM D638，塑料蠕变与热变形也有专门方法。这里只给出检索方向，不指定当前有效版号，不声称符合标准。实际开展标准试验前，须取得适用版本并按其试样、调湿、加载和报告要求执行。
