# 材料组织：成分相同，性能为什么不同？

材料性能由成分、内部组织和制造历史共同决定。理解这条关系，就不会把“6061”“钢”或“尼龙”当作完整的采购规格。

## 金属：晶粒、位错与第二相

金属通常由许多晶粒组成。塑性变形与位错运动有关；合金元素、细小析出物、晶界以及冷加工形成的位错结构，都可能阻碍位错运动，提高屈服强度。强化也可能改变延性、韧性、耐蚀性和加工性，不能把这些效果视作同步改善。

| 机制 | 改变了什么 | 在机器人中的关联 |
|---|---|---|
| 固溶强化 | 溶质影响晶格与位错运动 | 理解合金化为何改变强度 |
| 加工硬化 | 冷变形改变位错结构 | 薄板成形后性能与残余应力变化 |
| 析出强化 | 热处理形成阻碍位错的析出物 | 6xxx 铝合金状态与焊接软化 |
| 相变与回火 | 调整钢的组织与内应力 | 轴、齿轮的强度、韧性与变形控制 |
| 晶粒与织构控制 | 调整晶粒尺寸和取向分布 | 轧板、挤压件的方向差异 |

这些是概念层面的机制，不是可直接执行的热处理配方。实际温度、保温、冷却和后续检验需要按牌号与产品规范确定。

## 热处理状态也是材料名称的一部分

铝合金中的 T6 通常指固溶热处理后人工时效；T4 通常指固溶热处理后自然时效。T651、T6511 等还包含与产品形态相关的消除应力和加工状态要求，不能把板材和挤压材的尾缀随意互换。

例如，6061-T6 母材的性能不能直接作为焊缝及热影响区的性能。焊接局部加热会改变强化组织；焊后结构需要考虑软化区、焊接缺陷与疲劳。参见 [Hydro 6061 状态说明](https://www.hydro.com/globalassets/01-products--services/extruded-profiles/americas/ena-resources/alloy-data-sheets/hydro_2019_data_sheet_6061.pdf)。

## 聚合物：链段运动比名称更能解释行为

热塑性塑料受热后可软化加工；热固性树脂形成交联网络，固化后一般不能再次熔融成形。弹性体依靠分子网络产生较大的可恢复形变。

非晶态与半结晶态会影响收缩、尺寸稳定性和温度响应。玻璃化转变温度 $T_g$ 描述非晶部分链段运动的变化；熔融温度 $T_m$ 与晶体区域熔化相关。半结晶聚合物可以同时有这两种转变。

**HDT、$T_g$、$T_m$ 和连续使用温度不是同一指标。** HDT 是规定试验载荷与方法下的热变形指标；某材料打印喷嘴温度高，也不代表打印件能在该温度承重。实际设计还要看时间、湿度、几何和允许变形。

## 填料、纤维和方向性

玻纤或碳纤可能提高某方向的模量、降低热膨胀，同时改变冲击、层间结合、表面磨损和加工难度。短纤维增强打印料并不等于连续纤维层合板。只看到“CF”后缀，不能得出所有方向都更强的结论。

聚合物的含水状态也属于材料状态。尼龙吸湿可能改变尺寸与力学性质；加工前干燥和使用前调湿是两个不同目的。参见 [Toray 尼龙加工前注意事项](https://www.plastics.toray/technical/amilan/tec_007.html)。

## 读数据表的顺序

先看商品牌号、基体与填料，再看试样是注塑、机加工还是打印，随后确认方向、含水、温度、试验方法和统计口径。最后才看数值。缺少这些条件的“强度 60 MPa”，不足以用于结构验算。

**练习：** 找到一个打印耗材的数据表，标出它测的是原料还是成品、哪个方向、何种温度，以及是否包含长期蠕变数据。没有说明的项目标为“未知”。
