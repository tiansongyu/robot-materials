# 复合材料、弹性体与功能材料

当铝、钢和常用塑料无法同时满足需求时，才需要引入更专门的材料。关键是理解它解决哪一个问题，以及新增加了哪些约束。

## 碳纤维：性能沿方向分布

连续碳纤维增强聚合物由纤维与树脂共同工作。纤维方向对拉伸与弯曲承载很重要；树脂、界面和铺层则关系到剪切、层间损伤、温度与环境响应。单向材料不能只用一个弹性模量描述所有方向。

| 形式 | 要看什么 | 适合的学习场景 |
|---|---|---|
| 短切碳纤打印塑料 | 基体、纤维比例、打印方向、层间结合 | 对比普通塑料与填充塑料样件 |
| 连续纤维层合板 | 铺层、厚度、开孔与层间性能 | 平面轻量结构与夹板 |
| 碳纤维管 | 轴向、环向及斜向铺层，端部连接 | 长连杆与支撑杆候选 |
| 夹芯结构 | 面板、芯材、胶层、局部压溃 | 需要高弯曲刚度的面板 |

厂家给出的纤维本体性能不是最终层合板性能。可从 [Hexcel 预浸料技术手册](https://www.hexcel.com/wp-content/uploads/2026/01/Prepreg_Technology.pdf)理解方向、基体和铺层的分工。

## 连接通常比杆件本体更难

碳纤维管不能只按轴向强度选定，再随意拧紧一个尖边夹具。夹持会引入径向压缩和层间损伤；钻孔会切断纤维，并改变载荷路径。可考虑带足够接触面积的端接或经过验证的胶接，但胶层厚度、表面处理、剥离和环境老化都需验证。

碳纤维与铝在潮湿导电环境中接触还需要评估电偶腐蚀，使用适当的电隔离与密封设计。不能仅靠表面看起来完好，就推断内部没有分层。

## 其他材料在机器人中的位置

| 材料族 | 功能角色 | 不应忽略 |
|---|---|---|
| 硅橡胶、聚氨酯等弹性体 | 密封、触觉接触、缓冲 | 压缩永久变形、介质兼容、温度 |
| 铜及铜合金 | 导电、散热、某些滑动零件 | 质量、绝缘、接触腐蚀 |
| 钛合金 | 特定强度、质量与耐蚀约束 | 成本、加工、摩擦咬合与连接 |
| 氧化铝等工程陶瓷 | 绝缘、耐磨或热管理 | 脆性、冲击、表面缺陷 |
| 热解石墨 TPG | 热扩散 | 强烈方向性与封装要求 |

TPG 的热导率随方向而异，不能把平面方向数据作为厚度方向数值使用。它是热设计的候选，不应与 PETG 塑料混淆。[Momentive TPG 产品说明](https://www.momentivetech.com/materials/ceramic-materials/thermal-pyrolytic-graphite-tpg)。

## 练习

为一根长机械臂连杆比较“铝管”与“碳纤维管＋金属端接”。把端接、紧固件、防护、维修和验证成本算入，再比较总质量与刚度。只有杆身变轻，不足以证明整套结构更优。
